# โครงการ พัฒนาเกมเนื้อเรื่อง 2D ด้านความปลอดภัยไซเบอร์ (Cybersecurity Educational Game)

## 📌 ภาพรวมของโปรเจกต์ (Project Overview)

โปรเจกต์นี้คือการสร้างและพัฒนาเกมเนื้อเรื่อง 2D ที่มุ่งเน้นการให้ความรู้ด้านความปลอดภัยทางไซเบอร์ [Cybersecurity](cite: 1) ผู้เล่นจะได้สวมบทบาทเป็นนักศึกษาที่ต้องรับมือกับภัยคุกคามทางไซเบอร์ โดยต้องแก้ปริศนาและสืบสวนเหตุการณ์ต่างๆ เช่น การตรวจสอบอีเมลปลอม (Typosquatting), การอ่าน Windows Event Log, การแกะรอยมัลแวร์, และการกู้คืนข้อมูลอย่างปลอดภัย[cite: 1]

ระบบของโปรเจกต์ถูกออกแบบให้ทำงานร่วมกันระหว่างฝั่งเกมเพลย์และการวิเคราะห์ข้อมูลพฤติกรรมของผู้เล่น ดังนี้:

* **ฝั่งผู้ใช้งาน (Client):** พัฒนาตัวเกมด้วย Godot Engine เพื่อนำเสนอเนื้อเรื่องแบบ 2D และดักจับพฤติกรรมต่างๆ ของผู้เล่น [เช่น การคลิก การตัดสินใจ และเวลาที่ใช้](cite: 2)
* **ฝั่งระบบหลังบ้าน (Backend & Analytics):** ใช้ FastAPI (Python) ในการรับข้อมูลและตรวจสอบความถูกต้อง ก่อนบันทึกลง SQL Database[cite: 2]
* **การประมวลผลและการแสดงผล (Data Processing):** ข้อมูลในฐานข้อมูลจะถูกนำไปวิเคราะห์ด้วย Machine Learning (Scikit-Learn) เพื่อจัดกลุ่มผู้เล่น และแสดงผลสถิติแบบ Real-time ผ่าน Power BI[cite: 2]

## 📂 โครงสร้างไฟล์ (File Structure)

โปรเจกต์นี้ถูกแบ่งโฟลเดอร์หลักตามสถาปัตยกรรมของระบบ เพื่อให้ง่ายต่อการพัฒนาควบคู่กัน:

```text
cyber-game-project/
├── .github/                    # สำหรับตั้งค่า GitHub Actions (CI/CD) และ Issue Templates
├── docs/                       # เก็บเอกสารการออกแบบต่างๆ
│   ├── AI_scene.md             # ไฟล์ Story Board เนื้อเรื่องและปริศนาในเกม
│   └── Conceptual_Architecture.md # ไฟล์ผังระบบสถาปัตยกรรม
├── game-client/                # โฟลเดอร์หลักของตัวเกม (Godot Engine)
│   ├── project.godot           # ไฟล์ตั้งค่าหลักของโปรเจกต์ Godot
│   ├── scenes/                 # เก็บไฟล์ฉาก (Scenes) ที่ใช้ในเกม
│   ├── scripts/                # สคริปต์ควบคุมการทำงานของเกม
│   └── assets/                 # ทรัพยากรเกม (รูปภาพ, UI, เสียง)
├── backend-api/                # โฟลเดอร์ระบบหลังบ้านและ API (FastAPI)
│   ├── main.py                 # ไฟล์เริ่มต้นสำหรับรันเซิร์ฟเวอร์
│   ├── models/                 # โครงสร้าง Data Model (Pydantic)
│   ├── routes/                 # API Endpoints สำหรับรับส่งข้อมูลกับเกม
│   └── requirements.txt        # รายการไลบรารี Python สำหรับ Backend
├── database/                   # สคริปต์และการตั้งค่าฐานข้อมูล
│   └── schema.sql              # โครงสร้างตารางใน SQL Server
├── data-analytics/             # โฟลเดอร์สำหรับการวิเคราะห์และการแสดงผลข้อมูล
│   ├── ml-pipeline/            # สคริปต์ Machine Learning สำหรับวิเคราะห์พฤติกรรม
│   └── bi-dashboards/          # ไฟล์หรือเทมเพลตสำหรับเชื่อมต่อ Power BI
├── .gitignore                  # กฎการละเว้นไฟล์ที่ไม่ต้องการอัปโหลดขึ้น Git
└── README.md                   # เอกสารแนะนำโปรเจกต์ (ไฟล์นี้)
```
