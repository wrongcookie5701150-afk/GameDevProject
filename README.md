# เนื้อเรื่อง

## Scene 1: เวลา 19.02 น.

น้องไทน์เปิดคอมพิวเตอร์ในห้องนอน เปิดเอกสารรายงานไปด้วย ฟังเพลงเพลิน ๆ ผ่านหูฟัง เสียงภายนอกแทบไม่ได้ยิน

พอดีมีสายจากน้องมิวโทรมา
*มิว : “ไทน์ ยังไม่ส่งไฟล์ส่วนที่แก้ไขเลยนะ พรุ่งนี้จะเดดไลน์แล้วนะ”*

---

น้องไทน์ถอนหายใจ แล้วเปิด Google Drive ขึ้นมา ในโฟลเดอร์มีไฟล์ใหม่ชื่อ `Final_Project_Update_v3.docx`  (เวลากำกับ แก้ไขล่าสุดเมื่อ 10 นาทีที่แล้ว)

น้องไทน์คลิกเปิดไฟล์ขึ้นมา หน้าต่าง Word โผล่ขึ้นมา พร้อมข้อความแจ้งเตือนเล็ก ๆ 
![](https://learn-attachment.microsoft.com/api/attachments/5e1c3bf8-c753-4a87-992d-f970a822d50a?platform=QnA)

น้องไทน์กด “Enable Content” โดยไม่คิดมาก 
*ไทน์ : "ไฟล์แบบนี้อีกละ"*

ไทน์ไปติ๊ก unblock macro
![](https://learn-attachment.microsoft.com/api/attachments/2ac99fdb-6518-48da-ad93-613d13113f3c?platform=QnA)

ขณะที่กำลังเลื่อนดูเนื้อหาในไฟล์ หน้าจอคอมพิวเตอร์มีป๊อปอัปขึ้นมาหลายครั้ง:

- ข่าวด่วนเรื่องอากาศร้อน
- การแจ้งเตือนจากเบราว์เซอร์เรื่อง “อัปเดตโปรแกรม”
- ป๊อปอัปจากโปรแกรมป้องกันไวรัสที่บอกว่า “ไม่พบภัยคุกคาม”

น้องไทน์มองผ่าน ๆ แล้วปิดมันทิ้ง และเช็คเนื้อหา และแก้ไขต่อไป
